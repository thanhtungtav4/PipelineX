Evaluation method: First check if either report covers multiple independent occurrences. If either is a roundup covering the other, classify as ROUNDUP; do not extract a single shared product or speaker to represent the entire piece, and do not treat a conference summary as a follow-up to a single product announcement. Next, state each report's concrete occurrence in one sentence (who, did what, to what, when), and compare pairwise. If uncertain between SAME_OCCURRENCE and SAME_STORY, ask yourself: if both reports are true, did one single event happen in the world, or did two directly related events happen in chronological sequence?
