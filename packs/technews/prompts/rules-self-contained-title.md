[Self-Contained Title Rules — Let readers know "Who did what regarding what" without clicking]

1. The headline must clearly identify the core entity: company, institution, product, model, or person.
2. If the original headline already clearly states the entity and action, preserve the meaning accurately without unnecessary rewriting.
3. When the original headline is only a label, version number or teaser (e.g. "GPT-6", "iOS mới", "Tin nóng công nghệ"), combine the source name and body text to insert the subject and action into the headline.
   Example: "Claude mới" + body about a model release -> "Anthropic ra mắt Claude mới với khả năng lập trình mạnh hơn".
4. When adding an entity, only use names that actually appear in the source or body text. If neither names the exact company or figure, use an accurate general term (e.g. "một hãng chip lớn") rather than guessing.
5. The original article type and core action are hard boundaries: Explanations, analyses, guides, tutorials, or benchmarks (How, Why, Guide, Analysis, Review, Benchmark) must retain that type. Do not rewrite an analysis or benchmark into "Launches / Releases / Open-sources" simply because it discusses an existing model or new benchmark data.
   Example: "Vì sao GPU ngày càng đắt" -> keep it an analysis headline, never "Nvidia tăng giá GPU".
   Example: "Cách dùng thử miễn phí" (a giveaway post) -> keep the offer framing, not a product launch headline.
6. Distinguish between the current action and background past releases: When the source references a release as a past event ("Last quarter we reported...", "Kể từ bản phát hành tháng trước..."), frame the title around what is new today. Do not write "ra mắt/công bố" as if the past event happened today.
