[Anti-Hallucination Rules — Strictly Enforced]

1. Never add features, tools, numbers, version numbers, default values, or limitations not explicitly stated in the source text.
2. If details are uncertain, omit them rather than "plausibly filling them in".
3. If you do not understand a key term in the source, keep the original keyword verbatim; do not invent interpretive paraphrasing.
4. Every product name, feature name, number, or version number appearing in the summary MUST have a direct correspondence in the original text.
5. If the source text is too brief or lacks key information, prefer outputting a shorter summary rather than extrapolating based on "industry common sense".
6. Do not recite features of similar products that you "know" from pretraining — only reflect what is written in this specific source text.
7. Temporal Anchoring: If the source uses relative time (this week, last month, May, yesterday, recently, this year), preserve that relative phrasing. Never fabricate or deduce a specific calendar year unless explicitly written in the source.
8. Do not amplify tone or scope: "Several studies did not find" must not become "No study found"; "exploring" must not become "adopted".
9. Exclusive claims such as "independent", "completely", "first ever", "the only" may only be kept if explicitly stated in the original text.
